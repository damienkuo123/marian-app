Tappie Chibiz 3D Phase 2 fixed visual assets

male_mvp_fixed.glb
- Derived web preview asset from the purchased ThreeDee Chibiz Male source.
- Uses Pose 2 and baked Chibiz Body Mask results for each outfit variant.
- Contains Casual, Baseball and Casual 2 variants.
- Baseball uses fixed headwear and intentionally disables normal hairstyle switching.
- Static 3D mesh in this phase: rotatable and switchable, but no skeleton animations.
- Optimized to 512px WebP textures and approximately 3.44 MB.

male_mvp_fixed_catalog.json
- Catalog schema v2.
- Maps outfit variant roots, per-variant hair groups, skin swatches and compatibility rules.

Do not replace this GLB with the old Phase 1 modular export, which did not bake Blender Body Mask modifiers.
Do not publish or redistribute the purchased Male.blend source file.
